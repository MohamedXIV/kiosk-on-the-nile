# Buildings and Placement Corrections Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for the preserved Native execution method. Steps use checkbox (`- [ ]`) syntax. Written design approved; this implementation plan awaits review before product-code changes.

**Goal:** مبانٍ مغلقة ذات أبواب صحيحة وسقف يكشف بالدخول، مع سطح قابل للتجول وترتيب واضح ومحكوم ببيئة القطعة وقوائم مناسبة وحفظ قديم قابل للاستكمال.

**Architecture:** تبقى ملكية العناصر والمواضع في ItemStore وSpaceService. غرف البيانات وخلاياها تحدد داخل المبنى، وتستهلكها قواعد الوضع والرسم والتصادم وكشف السقف؛ لا حالة داخل/خارج محفوظة موازية لموضع اللاعب. يظل كشف السقف عرضًا مشتقًا، ولا تتغير رحلة التسوق أو الساعة عند عبور باب داخلي.

**Tech Stack:** Godot Standard 4.7.2، GDScript، Compatibility، Ink الحالي، JSON خارجي، نفس شبكة 0.25 ونظام الحركة والترتيب.

**Spec:** [التصميم المعتمد](../specs/2026-10-23-buildings-and-placement-corrections-design.md). مرجع التجربة [GAME_VISION](../../GAME_VISION.md). قاعدة كود المنتج `3a07e8d`؛ تعديلات الرؤية والمواصفات الحالية توثيقية.

## Global Constraints

- الباب في الجانب الأيمن للأوضة، وليس في فاصل وسطها أو في الحائط الأمامي. باب الأوضة ومدخل السلم تفاعلان مختلفان.
- الحوائط والأبواب والغرف للمطور فقط؛ صلاحيات اللاعب لا تتغير ولا تدخل الحفظ.
- نفس البيانات تحكم الرسم والتصادم والداخل/الخارج والمعاينة والتثبيت والمحرر والحفظ. يفحص الفوتبرنت كاملًا بعد الدوران، بما فيه الجهاز والحامل.
- لا تفقد قطعة أو محتوى أو مالًا أو عملًا أو حوارًا بسبب تغيير الهندسة. المرشح غير الصالح لا يستبدل الجلسة أو الحفظ السليم.
- لا بناء لأنظمة الزحام/الكرم/الحياة الاجتماعية ضمن هذه الخطة؛ لا تتغير قيم الإيقاع أو عدد الناس عرضًا أثناء إصلاح المكان.
- لا إضافة أو تشغيل automated tests دون طلب صريح وفق تعليمات الجلسة. البديل هنا build/import ومراجعة يدوية موثقة؛ لا تسمى خطوات لم تنفذ ناجحة.
- التنفيذ Native كما اختير سابقًا؛ مراجعة واحدة للفرع كله في النهاية وفق executing-plans، لا وكلاء تنفيذ أو مراجعة لكل مهمة.

## Review Focus

1. قطعة داخلية كبيرة أو جهاز مركب يدور عبر عتبة/زاوية: ترفض مساحة تتخطى البيئة المسموحة حتى إذا كان المركز داخلها — T1/T2.
2. باب يغلق أو شخص يتحرك بين المعاينة والتثبيت، أو رجوع من التسوق إلى موضع صار مسدودًا: يبقى الدخول والخروج ممكنًا ولا يظهر ممثل داخل جدار — T1/T2/T4.
3. كشف سقف عند الوقوف على العتبة، أو مع NPC داخل مبنى آخر، أو بعد ترتيب/Continue: يكشف المبنى الصحيح فقط ولا يحذف التصادم — T3.
4. حفظ قديم يحمل طعامًا على سطح أو دفعة في جهاز أو تنظيفًا متوقفًا أو Ink معلقًا: يحفظ النقل الذري المعرّفات والمحتوى والمواعيد والأدلة — T4.
5. مكتب منزلي أو قطعة مخزنة/معطلة أو وصفة غير معروفة: لا يفتح فهرس طبخ عامًا ولا يبدأ طبخًا عبر نداء مباشر يتجاوز سياق القطعة — T5.
